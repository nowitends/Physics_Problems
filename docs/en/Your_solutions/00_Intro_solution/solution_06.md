## 6. Function Analysis

We are given the function:

f(x) = 3x² − 12x + 7

To find local maxima or minima we compute the derivative.

---

### Step 1 — First derivative

f'(x) = 6x − 12

---

### Step 2 — Set derivative equal to zero

6x − 12 = 0

6x = 12

x = 2

---

### Step 3 — Second derivative

f''(x) = 6

Since f''(x) > 0, the function has a **local minimum**.

---

### Step 4 — Find the function value

f(2) = 3(2²) − 12(2) + 7

f(2) = 12 − 24 + 7

f(2) = −5

---

### Final Answer

The function has a **local minimum at:**

x = 2

f(2) = −5
