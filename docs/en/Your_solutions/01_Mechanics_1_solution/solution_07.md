Given:

x(t) = 2t^2  
y(t) = 3t^3  

---

From x(t):

x = 2t^2  
t^2 = x/2  

To eliminate t, square y:

y^2 = (3t^3)^2 = 9t^6  

Since t^6 = (t^2)^3:

t^6 = (x/2)^3  

So:

y^2 = 9(x/2)^3 = 9x^3 / 8  

---

Velocity:

v(t) = (dx/dt, dy/dt)

dx/dt = 4t  
dy/dt = 9t^2  

So:

v(t) = (4t, 9t^2)

Speed:

|v(t)| = √((4t)^2 + (9t^2)^2)
|v(t)| = √(16t^2 + 81t^4)

---

Acceleration:

a(t) = (d²x/dt², d²y/dt²)

d²x/dt² = 4  
d²y/dt² = 18t  

So:

a(t) = (4, 18t)

Magnitude:

|a(t)| = √(4^2 + (18t)^2)
|a(t)| = √(16 + 324t^2)

---

Is acceleration constant?

No, because the y-component (18t) depends on time.

---

Final answer:

y^2 = 9x^3 / 8

v(t) = (4t, 9t^2)

|v(t)| = √(16t^2 + 81t^4)

a(t) = (4, 18t)

|a(t)| = √(16 + 324t^2)

Acceleration is not constant.
